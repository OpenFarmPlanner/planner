## Confirmed bugs

### 1. Sign-in and account messages ignore the UI language — [#1657](https://github.com/OpenFarmPlanner/planner/issues/1657) (P1)

| Step | UI language | Shown |
| --- | --- | --- |
| `/login`, wrong password | en, fr, de | "Ungültige Zugangsdaten." |
| `/forgot-password`, submit | en, fr, de | "Falls das Konto existiert, wurde eine E-Mail gesendet." |
| Account settings → change password, wrong current password | de, en, fr | "Invalid password." |
| Same, correct current password | en, fr | "Dein Passwort wurde erfolgreich geändert." |

Each row was reproduced in two or more independent runs at 1440×900. All
surrounding text was correctly localized. Cause:
`frontend/src/auth/authApi.ts` maps backend messages by exact English prose,
while `backend/accounts/views.py` sends `_de()` German text (plus a `code`).
"Invalid password." and four other `_de()` messages are missing from
`accounts/locale/de/LC_MESSAGES/django.po`.

Process note in the issue: `ops/deploy/deploy_backend.sh` runs no
`compilemessages`. Production uses whatever `.mo` files are in the operator's
local checkout (gitignored, rsynced).

### 2. Yield legend and crop filter drop the variety — [#1658](https://github.com/OpenFarmPlanner/planner/issues/1658) (P3)

Ertragsübersicht → Prognosekalender, demo dataset: the legend shows "Salat 56 kg"
and "Salat 7,2 kg" in near-identical greens, and the "Kultur" filter lists "Salat"
twice (Lollo Bionda vs. Maikönig). Reproduced 3× (2 × 1440×900, 375×800).
`useYieldChartData.ts` uses `getCropDisplayName` instead of `formatCropDisplayName`.

### 3. Season comparison chart runs newest-first — [#1659](https://github.com/OpenFarmPlanner/planner/issues/1659) (P3)

"Saisonen vergleichen": chart x-axis 2027 | 2026 | 2025, crop table below
2025 | 2026 | 2027. Reproduced at 1440×900 and 375×800. `YieldCropMatrix.tsx`
reverses the newest-first API order; `YieldSeasonChart.tsx` does not.
